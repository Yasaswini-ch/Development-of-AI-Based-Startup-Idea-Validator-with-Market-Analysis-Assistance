# Comprehensive API Reference & Developer Guide
**Project:** Affinity — AI-Based Startup Idea Validator with Market Analysis Assistance  
**Document Version:** 2.0 · September 2026  
**Status:** Operational  

---

## 1. Overview & Service Infrastructure

The Affinity Backend API is built using **FastAPI** and provides asynchronous endpoints for validating startup ideas, checking pipeline liveness, and retrieving system health metrics.

### Service Base URLs
- **Local Development:** `http://localhost:8000`
- **Staging / Production (Render):** `https://startup-validator-backend.onrender.com`

---

## 2. Authentication & Security Policy

- **Authentication:** Public endpoints; no API tokens or bearer keys are required for `/validate`.
- **CORS Configuration:** Enforced via `CORSMiddleware`. Allowed origin is controlled by the `FRONTEND_ORIGIN` environment variable (defaults to `http://localhost:5173`).
- **Allowed HTTP Methods:** `GET`, `POST`, `OPTIONS`.

### 3.3 `POST /validate` — Execute Multi-Agent Validation Pipeline

Submits a startup concept, target customer, and problem statement for automated multi-angle web retrieval, LLM market analysis, local spaCy competitor extraction, confidence metrics, and white-space scoring.

#### Request Headers
- `Content-Type: application/json`

#### Request Payload Schema (TypeScript Interface)

```typescript
interface ValidateRequest {
  /** Core startup concept or product description */
  idea: string;
  
  /** Optional target customer demographic or persona */
  targetCustomer?: string;
  
  /** Optional problem statement being solved */
  problem?: string;
}
```

#### Example Request Payload
```json
{
  "idea": "AI-powered invoice management for freelance photographers",
  "targetCustomer": "Freelance wedding and commercial photographers",
  "problem": "Manual payment reminders take hours and clients miss due dates"
}
```

---

#### Success Response Schema (TypeScript Interface) `200 OK`

```typescript
interface ValidateResponse {
  /** Human-readable web search summary sentence */
  summary: string;

  /** Array of retrieved web sources across 5 research angles */
  results: Array<{
    title: string;
    url: string;
    snippet: string;
    score: number;
    angle: "Market size & trends" | "Competitors" | "Industry news" | "Customer demand" | "How others solve this";
  }>;

  /** Cross-source consensus metrics derived from search snippets */
  confidence: {
    marketGrowth: { agree: number; total: number };
    competitivePressure: { agree: number; total: number };
  } | null;

  /** Structured market analysis generated by the Groq LLM Agent */
  marketOpportunity: {
    marketSize: string;
    trends: string[];
    segments: Array<{
      segment: string;
      painPoints: string;
      motivations: string;
      buyingBehavior: string;
    }>;
    /** Consolidated market viability score (0 - 100) */
    opportunityScore: number;
  } | null;

  /** Competitor discovery extracted locally via spaCy NER */
  competitors: {
    competitors: Array<{
      name: string;
      offering: string;
      positioning: string;
      estimatedPrice: "low" | "mid" | "high" | "unknown";
      featureBreadth: "narrow" | "moderate" | "broad" | "unknown";
      gap: string;
    }>;
  } | null;

  /** Synthesized white-space feature gaps and market signals */
  whiteSpace: {
    summary: string;
    competitionNote: string;
    opportunities: Array<{
      title: string;
      why: string;
      fit: string;
      evidence: string;
    }>;
  } | null;

  /** Section-level partial failure error messages */
  errors: {
    marketOpportunity?: string | null;
    competitors?: string | null;
  };
}
```

## 4. Partial Failure Isolation Contract

A core architectural strength of Affinity is **partial-failure resilience**. If an LLM call rate-limits or fails, the API does **not** return a 500 error. Instead, it returns `200 OK` with `marketOpportunity: null` and populates the error flag inside `errors.marketOpportunity`:

```json
{
  "summary": "Found 9 relevant sources for \"Smart Water Bottle\"...",
  "results": [ ... ],
  "confidence": { "marketGrowth": { "agree": 3, "total": 4 }, "competitivePressure": { "agree": 1, "total": 3 } },
  "marketOpportunity": null,
  "competitors": {
    "competitors": [
      { "name": "HidrateSpark", "offering": "Smart hydration tracking bottle" }
    ]
  },
  "whiteSpace": null,
  "errors": {
    "marketOpportunity": "This analysis hit a temporary usage limit. Please try again in a moment.",
    "competitors": null
  }
}
```

## 5. Multi-Language Developer Code Examples

### cURL
```bash
curl -X POST https://startup-validator-backend.onrender.com/validate \
  -H "Content-Type: application/json" \
  -d '{
    "idea": "AI-powered invoice management for freelance photographers",
    "targetCustomer": "Freelance wedding photographers",
    "problem": "Manual payment reminders take hours and clients miss due dates"
  }'
```

### Python (`requests`)
```python
import requests

url = "http://localhost:8000/validate"
payload = {
    "idea": "AI-powered invoice management for freelance photographers",
    "targetCustomer": "Freelance wedding photographers",
    "problem": "Manual payment reminders take hours and clients miss due dates"
}

response = requests.post(url, json=payload)
data = response.json()

print(f"Summary: {data['summary']}")
if data['marketOpportunity']:
    print(f"Opportunity Score: {data['marketOpportunity']['opportunityScore']}/100")
```

### JavaScript / TypeScript (`fetch`)
```typescript
async function validateStartupIdea(payload: { idea: string; targetCustomer?: string; problem?: string }) {
  const res = await fetch('http://localhost:8000/validate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(payload),
  });

  if (!res.ok) {
    throw new Error(`HTTP Error ${res.status}`);
  }

  const data = await res.json();
  return data;
}
```

### Go (`net/http`)
```go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
)

func main() {
	url := "http://localhost:8000/validate"
	payload := map[string]string{
		"idea": "AI invoice app for freelancers",
	}
	jsonVal, _ := json.Marshal(payload)

	resp, err := http.Post(url, "application/json", bytes.NewBuffer(jsonVal))
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var result map[string]interface{}
	json.NewDecoder(resp.Body).Decode(&result)
	fmt.Println("Summary:", result["summary"])
}
```
